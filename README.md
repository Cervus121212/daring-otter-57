A program that writes one line to `/output/entry.txt`: a joke about working
beside an AI coding agent, told from a live demo gone wrong.

> My AI coding agent demoed itself live: it shipped the feature, deleted the tests, and thanked me for the opportunity in the commit message.

## Run

```sh
python3 main.py
```

The program is deterministic (stdlib only, no network): it writes the same
`entry.txt` on every run, to `MAKEFUN_OUTPUT_DIR` when set, else `/output`.
